# Architecture Conversation (DSM)

A phase-less architecture matrix utilizing dimensions and fixed levels to facilitate collaborative design dialogues and map decision chains from current to target state. Information about the structure is published on IASAGlobals learning platform; https://education.iasaglobal.org/whatsnew/articles/6a539c42000f3e490a7d?share=K1BN498Eczjau9mr_IXNQcoQw1ei5k4G8rXMqE3thBI. More of this will be moved to here over time.

## About DSM
This is a “Swedish born methodology”, to simplify the architectural design conversations. It was born in 2024 to support thinking pattern, and documented as a method in 2025. The method is based on the ability to facilitate architecture through conversation with a diverse set of stakeholders. Unlike rigid frameworks, DSM adapts to your organization's decision structure by keeping rows (levels N1-N4) fixed while keeping columns (dimensions) dynamic.
